# IUT Lean Reference Library

An English, source-audited and pedagogical Lean reference for a small finite
symmetry layer appearing in *Inter-universal Teichmüller Theory I*.

**Repository status.** This is a published independent release-candidate
project containing a verified Lean formalization of a bounded algebraic and
coordinatized fragment motivated by IUT I. “Published” describes public
distribution and licensing. It does not mean that the artifact has been
incorporated into the canonical `IUT1-I1-SYM-001` study unit, adopted by
Project LANA, or promoted to an official IUT formalization. The canonical
project ledger remains separate, closes at T05 and records `promotion=false`.

Existing PASS labels apply only to their named bytes and gates. They are not
transferred to canonical incorporation, geometric realization, Project LANA
acceptance, the corrective rc2 package as a whole, or expert human source
approval.

The first release consolidates the requested T01--T08 core and three
non-geometric closure/regression targets, T09--T11. It is designed for three audiences:
mathematicians who do not program in Lean, Lean users who do not specialize in
IUT, and retrieval or training pipelines that need claims with explicit
provenance and epistemic limits.

The package is oriented to practical use by the LANA and IUT research
communities: source-to-type review, adversarial interpretation tests,
formalization handoffs, reproducible finite examples and AI retrieval with
non-claims attached. It is independent and is not an official Project LANA
artifact or an assertion of compatibility with a LANA code API.

| T03 | the sign subgroup generated by `-1` has order two | semantic, kernel, fidelity and replication PASS |
| T04 | the unit quotient by sign has `(l-1)/2` elements | semantic, kernel, fidelity and replication PASS |
| T05 | a distinguished orbit of sign-compatible charts descends coherently to sign quotients; a closed countermodel tests overgeneralization; the additive quotient has `(l+1)/2` classes | semantic, kernel, fidelity and replication PASS |
| T06 | the visible signed-affine pair law defines a group | semantic, kernel, fidelity and replication PASS |
| T07 | multiplication agrees with right-to-left affine composition | semantic, kernel, fidelity and replication PASS |
| T08 | the signed-affine group has `2*l` elements | semantic, kernel, fidelity and replication PASS |
| T09 | translations form a normal subgroup of index two | semantic, kernel, fidelity and replication PASS |
| T10 | an explicit dihedral equivalence preserves the displayed action | semantic, kernel, fidelity and replication PASS |
| T11 | typed cardinality regressions at `l=5` and `l=7` | semantic, kernel, fidelity and replication PASS |

Every PASS is tied to exact source hashes. A semantic PASS is not treated as a
kernel PASS, and neither is transferred to source fidelity or cold replication.

## What is not claimed

These results are finite algebraic and coordinatized. They do not formalize IUT
I, construct cusp geometry, realize the groups as geometric automorphism or
Galois groups, construct the source's geometric poly-actions, or prove the transition from IUT III
3.11 to 3.12. They do not prove Szpiro or abc.

The package does contain an explicitly qualified algebraic prototype of
collection-valued morphisms and quotient fibers. Its Boolean and `l=5`
examples test whether an interface preserves multiple arrows; they do not
upgrade the finite model to an IUT poly-action.

The mathematics of T01--T11 is not new. Generic semidirect-product results are
already in Mathlib, and an IUT-oriented Lean antecedent already proves the
`2*l` cardinal through a dihedral model. The contribution here is a more
traceable interface: source locators, visible coordinates, rival-discriminating
examples, independent gates, and machine-readable claim records.

## Lean layout

The verified declarations live in four source-facing modules:

```text
src/IUT1/SymmetryCore.lean       T01--T04
src/IUT1/SignOrbitBridge.lean    T05a--T05d
src/IUT1/SignedAffineCore.lean   T06--T08
src/IUT1/SignedAffineDihedral.lean T09--T11
src/IUT1/Tutorial.lean           commented reading path and closed examples
src/IUT1/Applications/ConventionAudit.lean exhaustive convention discriminator
src/IUT1/Applications/PolyMorphismPrototype.lean PA01--PA06 algebraic prototype
test/IUT1/*.lean                 #print axioms and separation audits
```

The core modules are byte-preserving exports of independently reviewed local
artifacts. Pedagogical additions are placed in `Tutorial.lean`, so explanatory
growth cannot silently alter the proofs that received PASS.

## Build

Install Lean through `elan`, then run:

```text
lake update
lake exe cache get
python scripts/validate_release.py
python scripts/check_lean_policy.py
python scripts/check_axiom_surface.py
lake build
python scripts/check_axiom_surface.py --run
lake env leanchecker IUT1 IUT1Audit
```

The repository pins Lean `4.28.0` and Mathlib commit
`8f9d9cff6bd728b17a24e163c9402775d9e6a365`. The local release candidate is
also compiled file-by-file against that environment, with a separate axiom
audit and an isolated cold replication.

## Source access

The source PDFs are not redistributed. The machine-readable records identify
the official source, its SHA-256, printed-page locators and public access URL.
This keeps the repository useful while respecting the source corpus's
redistribution boundary.
