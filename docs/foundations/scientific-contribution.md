# Scientific contribution and novelty status

## Result of the priority audit

The group law, affine action, cardinalities, translation subgroup and dihedral
comparison formalized here are established mathematics. Takkun's IUT-oriented
Lean repository already contains a dihedral model with the `2*l` cardinality.
Accordingly, this project does not claim a new mathematical theorem or the first
Lean formalization of the shared algebraic content.

A bounded public-priority search did not locate the exact combination of visible
signed-affine coordinates, claim-level IUT-I locators, executable rival
conventions, separate semantic/kernel/fidelity/replication gates and an
AI-oriented evidence schema. That negative result is
`NOT_FOUND_WITHIN_AUDITED_PUBLIC_SCOPE`, not a certificate of global novelty.
Discovery of an earlier matching artifact would narrow the contribution without
changing the correctness of the verified Lean declarations.

## What the work contributes

The substantive contribution is an auditable scientific interface between a
small primary-source fragment, its coordinatized algebraic model and a formal
proof library. It adds six forms of value that are jointly absent from the
audited comparison slice.

First, every source-dependent claim retains a stable `source_id`, printed-page
localizer, epistemic status and explicit non-claims. This makes it possible to
distinguish what the source states from what the project derives or constructs.

Second, plausible rival interpretations are executable. Examples include the
direct-product mutation, reversed action order, omission of the zero orbit, an
overlarge chart family and the incorrect reflection coordinate `sr(a)`. A
formal model that merely compiles but accepts one of these rivals does not pass
the semantic contract.

Third, the APP01 convention auditor turns a theorem-specific sign check into a
reusable finite verification task. It accepts an arbitrary encoding and checks
action agreement over the full `SignedAffine 5 × Fl 5` domain. This is useful
for validating generated code, refactors and alternative presentations.

Fourth, the same content is synchronized across exposition, Lean
formalization, applications and replication evidence. Machine-readable claim,
example, anti-pattern and application records make those distinctions
available to retrieval or training pipelines instead of burying them in prose.

Fifth, PA01–PA06 isolate the minimum algebraic obligations behind
collection-valued morphisms: retention of every arrow, pairwise composition,
exact composition of quotient fibers, the singleton boundary and a nontrivial
kernel discriminator. The Boolean example and the two-arrow `l=5` quotient
example are checked by `IUT1.PolyMorphism.PA01_bool_two_map_ne_singletons` and
`IUT1.PA06_signedAffine5_two_arrows_over_identity`. The scientific value lies
in making an interface error falsifiable while denying geometric realization.

Sixth, the package exposes concrete source-review, formalization-handoff,
adversarial-testing and AI-retrieval routes for LANA/IUT researchers. Every T
page answers the same operational questions and its poly-action role is
machine-readable. This does not claim official LANA status; it is an
independent contribution addressed to the same research community.

## Falsifiable quality advantage

The quality claim is scope-aligned, not global. For the finite coordinate
microdomain shared with the pinned Takkun commit, this package offers a complete
public theorem/instance axiom-audit denominator, full-file release manifest,
independent semantic and cold-replication gates, and explicit wrong-model
tests. The claim fails if any public declaration lacks its audit, any release
file is unregistered, any cited source binding is absent, or any discriminator
ceases to distinguish the intended model.

Takkun remains substantially broader: 68 Lean files and coverage extending
through IUT II--IV, compared with this deliberately bounded IUT-I coordinate
unit. Breadth is therefore an open program objective rather than a present
achievement.

## Scientific ceiling

This release establishes finite algebra and verification methodology. It does
not construct the geometric objects of IUT I, formalize a geometric poly-action,
complete IUT I, enter IUT II, bridge IUT III 3.11→3.12, or prove Szpiro or abc.
Those statements require new source contracts, mathematical constructions and
independent gates; neither repository size nor an AI-training objective can
substitute for them.
