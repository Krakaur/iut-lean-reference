## Plain mathematical translation

A signed-affine map is either a translation, with positive sign, or a
reflection followed by a translation, with negative sign. The positive-sign
maps form a subgroup. There are precisely two cosets, one for each sign, so the
translation subgroup has index two and is normal.

## Lean architecture

```lean
def translationSubgroup (l : ℕ) : Subgroup (SignedAffine l)

theorem T09_C06_translation_mem_iff (g : SignedAffine l) :
    g ∈ translationSubgroup l ↔ g.negative = false

theorem T09_C06_translation_index (l : ℕ) :
    (translationSubgroup l).index = 2
```

The subgroup is defined by the visible sign equation. Index two is proved with
the reflection `(0,true)`: right multiplication by this element toggles the
sign and therefore toggles membership. Normality is derived afterward using
the general theorem that every index-two subgroup is normal.

## Closed example and discriminator

`T09_example_l5_reflection_toggle` proves both that `(0,true)` is outside the
translation subgroup and that multiplication by it swaps membership for every
element of `SignedAffine 5`. This rejects a representation in which
“translations” are merely named but not tied to the coordinate law.

## What T09 does not establish

T09 does not identify this subgroup with deck transformations of a covering,
with a geometric automorphism group or with a Galois subgroup. Those
realizations require separate source-typed objects and proofs.
