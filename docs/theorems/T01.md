## Plain mathematical translation

The type used for an `l`-coordinate is the integers modulo `l`. It has exactly
`l` possible values. Primality is part of the source context and is needed for
the later field and unit arguments, although the carrier count itself is valid
more generally.

## Lean statement

```lean
theorem T01_C01_card_Fl : Fintype.card (Fl l) = l
```

`Fl` is an abbreviation, so the proof invokes Mathlib's cardinal theorem for
`ZMod`. No list of residues and no cardinality field are stored in the model.

## Example

`Tutorial.T01_example_l5` proves that `Fl 5` contains five elements. This fixes
the finite universe used by the later examples: `0,1,2,3,4` modulo five.

## Discriminator

T01 identifies only the coordinate carrier. It does not identify that carrier
with a cusp set, torsor, automorphism group or geometric object. Any later
theorem that needs such an identification must supply a source-backed map.

## Does not establish

T01 does not prove that an IUT label set exists, that a cover has `l` cusps, or
that a geometric action is realized. It also contains no novelty claim.
