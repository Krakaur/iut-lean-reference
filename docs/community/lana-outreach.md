# Responsible outreach to Project LANA

Verified on 2026-08-07.

## What is publicly available

Project LANA has a public-facing website and ZEN Mathematics Center (ZMC)
publishes LANA announcements, reports and events. ZMC links to a public GitHub
repository for the July 2026 interim report. These facts establish public
visibility; they do not establish open membership or a standing intake process
for external formalizations.

No official page reviewed for this release advertised a LANA account that an
external contributor can create, a general LANA code repository, or a public
contribution policy. The report repository exposes GitHub Issues and pull
requests as platform features, but it is a publication repository and does not
state that unsolicited project submissions are accepted there.

## Recommended sequence

1. Publish the contribution as an independent, citable repository with explicit
   scope limits, provenance, licenses and reproducible checks.
2. Use the official ZMC contact form to ask which channel, if any, LANA prefers
   for external technical material. Link to the repository; do not attach the
   private corpus or redistribute source PDFs.
3. Request feedback on three bounded questions: source fidelity, the usefulness
   of the Lean interfaces, and possible alignment with LANA's present roadmap.
4. Treat any response as correspondence, not as endorsement, membership or
   acceptance. Record permission before quoting private feedback publicly.
5. Discuss reusable abstractions with the Lean community before proposing them
   to Mathlib. A standalone repository is the correct present home for the
   IUT-specific pedagogical layer.
